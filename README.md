# CP 离线购物助手

逛展时，把心愿单、摊位地图、购物记录和无料领取放在一起。支持导入 CPP 心愿单，记录购买进度与花费，逛完后还能保存一张通关战报。

**当前场次：CPT-F · 福州 · 海峡国际会展中心 · 2026 年 11 月 7–8 日。** 地图包含 1–4 号同人馆及 9 号企业馆。

无需注册账号，清单保存在自己的设备上。通用版只需下载一个 HTML 文件；iPhone / iPad 使用添加到主屏幕的离线版。

## 下载与开始使用

| 你的设备 | 使用入口 |
| --- | --- |
| 安卓手机、电脑 | [下载通用版（单个 HTML 文件）](https://riiiiiii.github.io/cp-offline-shopping-assistant/index.html?download=1) |
| iPhone、iPad | [用 Safari 打开 iOS 版](https://riiiiiii.github.io/cp-offline-shopping-assistant/index_ios.html) |

### 安卓手机和电脑

1. 打开上方下载入口，再点击「下载通用版 index.html」，保存到设备中。
2. 用 Chrome、Edge 等浏览器打开这个文件。
3. 点击底部「添加 / 导入」，导入 CPP 导出的 Excel 心愿单，或手动添加条目。
4. 返回「地图」或「清单」即可开始使用。之后断网也能打开这个 HTML 文件。

如果在微信、QQ 等 App 内点击后没有下载，请选择“在浏览器中打开”后重试，也可以长按下载按钮选择“下载链接 / 链接另存为”。保存的文件名应以 `.html` 结尾。

如果打开已下载的文件后只有预览、按钮无法点击，请选择“用浏览器打开”。正式使用后尽量保留同一个文件位置和浏览器，更换前先导出备份，**出发前建议先备份.json格式文件**（具体方法见后文）。

### iPhone 和 iPad

1. 首次使用时连接网络，用 **Safari** 打开上方 iOS 版入口。
2. 在右上角「设置 → 安装与离线」中等待显示「缓存已就绪」。
3. 点击 Safari 的「分享 → 添加到主屏幕」。
4. 从主屏幕的 `CPT-F` 图标重新打开，**再导入心愿单**。
5. 在设置中确认显示「已安装 · 可离线」。出发前开启飞行模式，关闭后重新打开一次，确认可以离线使用。

Safari 网页与主屏幕应用可能分别保存数据，因此请先安装到主屏幕，再录入正式清单。iPhone 不建议直接从“文件”App 打开 HTML，预览模式可能无法正常使用。

首次打开会看到壹A01、壹A02 两个示例摊位，其中壹A01 带有待领取无料。体验后可以删除示例商品，并在摊位详情中取消示例无料标记。

## 导入或添加心愿单

在底部「添加 / 导入 → 从 Excel 导入」中，选择 CPP 导出的心愿单文件。导入后，商品会按摊位归类。

- 请保留表格中的「摊位号」和「展品名称」列；社团、原作、类型等信息也会一并读取。
- 再次导入同一份清单时，相同摊位号和商品名的条目会更新资料，已填写的价格、数量和购买状态会保留。
- 如果提示“部分摊位号未匹配地图”，这些商品仍然在清单中。请根据弹窗核对摊位号和所属场次。

也可以手动填写摊位号、展品名称，以及可选的社团、单价和数量，然后点击「加入 Wishlist」。

| 摊位类型 | 填写示例 |
| --- | --- |
| 普通摊位 | `壹A01`、`肆N26` |
| 连续摊位 | `壹A01-A02` |
| 3 号馆创摊 | `创016` |
| 3 号馆 CPA 区 | `CPA-08` |
| 9 号馆企业摊位 | `CPC08`、`企09` |

## 备份与换设备

**出发前、更新文件或更换设备前，建议先备份一次。**

- **导出：**「添加 / 导入 → 导出 JSON」，保存下载的备份文件。
- **恢复：**在准备使用的浏览器或主屏幕应用中，打开「添加 / 导入 → 导入 JSON」，选择此前的备份。

备份包含商品、价格、数量、购物状态、无料与备注、垃圾桶、透明度设置和最近一次战报。导入备份会覆盖当前清单，请先备份当前数据，并使用对应场次的文件。

心愿单不会自动上传或跨设备同步。不同浏览器、不同文件位置、网页和主屏幕应用可能有各自的数据；清理浏览器数据、使用无痕模式或删除主屏幕应用也可能使记录丢失。请保留自己的备份文件。


## 看地图、找摊位

在地图顶部选择「总览」或具体场馆。点击总览中的场馆进入详情，再点击「场馆设施与摊位区导航」中的区域，可以快速跳到对应摊位排。

总览、馆内导航和摊位标记使用相同的颜色含义：

| 颜色 | 含义 |
| --- | --- |
| 灰色 | 无意向：没有购物或无料记录 |
| 绿色 | 待购 / 待领：还有商品未购入或无料未领取 |
| 蓝色 | 已处理：该位置的购物与无料记录均已处理 |

点击摊位标记即可查看商品、修改购买状态、记录价格或标记无料。一个区域内只要还有待购或待领内容，就会保持绿色。

地图也标注了卫生间、咨询台、补给点、寄包处和医疗点等设施。**地图是相对位置示意，不提供实时定位和路线规划，请以现场指示为准。**

## 记录购买状态与花费

在「清单」中可以搜索摊位、商品、社团、原作或类型，并筛选待购、已购、完售条目。

- 点击商品状态，可在「尚未购入 → 已购入 → 已完售」之间切换。
- 点击摊位标题打开详情，可修改商品名、单价和数量，也可以将该摊位所有待购商品一次性标为已购。
- 顶部「已花」统计已购商品的金额；「当前预计」统计除完售外、已填写价格的商品金额。金额均按“单价 × 数量”计算。

需要删除商品时，在清单中按住商品名向左滑动；电脑上可向左拖动。误删后可以到「设置 → 垃圾桶」恢复，彻底删除后则无法撤销。

## 记录无料领取

在摊位详情中选择领取状态，并填写领取条件或备注：

| 圆章 | 状态 |
| --- | --- |
| 绿色星形 | 待领取 |
| 蓝色勾号 | 已领取 |
| 灰色叉号 | 已发完 |

没有计划购买商品，也可以通过「添加 / 导入 → 添加无料摊位」单独记录。清单中可筛选「无料待领取」或「所有无料」。

购买商品和领取无料分别记录。删除商品不会取消该摊位的无料；如果不再需要无料记录，请在摊位详情选择「未标记」，领取状态和备注会一起移除。

觉得地图标记太显眼时，可以在「设置」中分别调整「摊位标记透明度」和「无料印章透明度」。

## 结算时间

点击「设置 → 结算时间」，观看烟花并生成本次战报。战报会展示：

- 购入件数与有购入商品的摊位数。
- 已领取的无料和已记录的花费。
- 达成条件标签。

点击「保存战报图片」即可导出 PNG。像素字体已包含在应用中，无需另外安装字体，断网也可以保存图片。烟花可以跳过，系统开启“减少动态效果”时会省略动画。

结算后仍然可以继续逛展、补录商品。设置中可「查看上次战报」；如果希望图片反映最新记录，再点一次「结算时间」即可。


## 常见问题

### 点击下载后，为什么只看到代码？

旧的 GitHub Raw 链接可能会直接显示 HTML 源码。请回到上方下载入口，再点击页面中的「下载通用版 index.html」保存文件。

### Excel 导入失败怎么办？

优先使用 CPP 直接导出的文件，检查是否保留「摊位号」「展品名称」表头，并使用较新版本的浏览器。支持 `.xlsx` 以及 CPP 导出的兼容 `.xls` 文件，不支持旧式二进制 `.xls` 或受密码保护的工作簿。旧式表格可用 Excel 另存为 `.xlsx` 后再试，直接修改文件扩展名无效。

### 换了浏览器，为什么清单不见了？

清单保存在原来的浏览器中，并不会自动同步。回到原来的入口导出 JSON，再到新的入口导入即可。iPhone 用户请确认自己打开的是 Safari 网页还是主屏幕应用。

### 更新后如何保留记录？

先导出 JSON 备份。通用版下载新的 HTML 后，若清单没有自动出现，可以导入同场次备份；iOS 版先联网打开，等待离线缓存准备完成，再断网重开确认。

### 想重新开始，怎么清空清单？

使用「恢复为初始 Wishlist」会清除当前商品、价格、状态、无料、战报和垃圾桶，并恢复两个示例摊位。操作前请先导出备份。
